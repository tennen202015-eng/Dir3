# درع — تطبيق حماية الجوال

تطبيق أندرويد (Kotlin + Jetpack Compose) بالعربي، يدعم أندرويد 8 وأحدث.

## بيعمل إيه
- **فحص سريع للتطبيقات:** يراجع كل تطبيق متثبت ويديله درجة خطر حسب:
  - متثبت من المتجر الرسمي ولا من برّه
  - شغّال كخدمة إمكانية وصول (أخطر حاجة في فيروسات البنوك)
  - ماسك صلاحية مسؤول الجهاز
  - بيقرأ الإشعارات أو الرسائل (سرقة أكواد التحقق)
  - مستخبي من غير أيقونة
  - صلاحيات خطيرة: إرسال SMS، الظهور فوق التطبيقات، تثبيت تطبيقات، سجل المكالمات...
- **فحص سحابي عميق:** يحسب بصمة SHA-256 لكل تطبيق مشكوك فيه ويسأل عنها VirusTotal (أكتر من 70 برنامج حماية).
- **فحص ملف قبل فتحه:** تختار أي ملف أو APK، يتفحص أونلاين، ولو APK يعرض الصلاحيات اللي بيطلبها.
- **فحص إعدادات الجهاز:** قفل الشاشة، تاريخ تحديث الحماية، إصدار أندرويد، خيارات المطور، تصحيح USB، التشفير، الروت — ومعاه زرار «ظبطه».
- **فحص تلقائي كل 6 ساعات** + إشعار لو اتثبت تطبيق جديد مشبوه.
- أزرار: احذف التطبيق، افتح صلاحياته، أثق فيه.
- **فحص الروابط:** الصق رابط أو اعمل «مشاركة» لأي رسالة واختار «درع» — بيكشف التصيّد والروابط المختصرة والامتدادات المشبوهة.
- **كشف التقليد:** أي تطبيق أو موقع بيستخدم اسم بنك (الراجحي، الأهلي، STC Pay، CIB، InstaPay...) أو جهة حكومية (أبشر، توكلنا، نفاذ...) وهو مش رسمي بيطلع **خطر**.
- **قاعدة فيروسات يومية:** بصمات فيروسات أندرويد من MalwareBazaar، بتتحدث كل يوم في المستودع ده، والتطبيق بينزّلها لوحده من غير مفتاح.

## تشغيل قاعدة الفيروسات (مرة واحدة)
1. اعمل حساب مجاني في https://auth.abuse.ch وخد الـ **Auth-Key**.
2. في المستودع: **Settings → Secrets and variables → Actions → New repository secret**.
3. الاسم `ABUSECH_KEY` والقيمة المفتاح.
4. من **Actions → Update malware DB → Run workflow** شغّلها أول مرة (بعد كده هتشتغل لوحدها كل يوم).

> لازم المستودع يفضل **Public** عشان التطبيق يقدر ينزّل ملف القاعدة.

## إزاي تطلّع الـ APK

### الطريقة 1: GitHub (مجاني، ينفع من الجوال)
1. اعمل حساب على github.com، وبعدين **New repository** (خليه Private لو تحب).
2. **Add file → Upload files**، وارفع **محتوى** فولدر `Dir3` كله (مش الفولدر نفسه)،
   ومتنساش فولدر `.github` (لو مخفي عندك، اعمله بإيدك: Add file → Create new file
   واكتب الاسم `.github/workflows/build.yml` والصق محتواه).
3. ادخل تبويب **Actions** — هتلاقي «Build APK» شغال (حوالي 4–6 دقايق).
4. لما يخلص بعلامة ✓، افتحه وانزل تحت عند **Artifacts** ونزّل `Dir3-APK`، فكّه هتلاقي الـ APK.

### الطريقة 2: Android Studio على كمبيوتر
افتح فولدر `Dir3` في Android Studio ← استنى المزامنة ← Build ← Build APK(s).

## بعد التثبيت
- افتح **الإعدادات** في التطبيق وضيف مفتاح VirusTotal المجاني (virustotal.com ← حساب ← API key).
- الحساب المجاني بيسمح بـ 4 فحوصات في الدقيقة و500 في اليوم، عشان كده الفحص السحابي بيستنى 16 ثانية بين كل تطبيق.

## حدود لازم تعرفها
- أندرويد بيعزل كل تطبيق عن التاني، فمفيش أي تطبيق حماية (حتى المشهورة) يقدر يدخل جوه بيانات تطبيق تاني. الفحص بيعتمد على الصلاحيات والمصدر والبصمة.
- التطبيق ده بيكمّل Google Play Protect ومش بديل عنه.
- الـ APK ده نسخة debug مناسبة للاستخدام الشخصي. لنشره على Google Play محتاج توقيع release، وجوجل بتطلب تبرير لصلاحية `QUERY_ALL_PACKAGES` (تطبيقات الحماية من الحالات المقبولة).
